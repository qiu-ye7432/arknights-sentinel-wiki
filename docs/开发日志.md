# 卫戍协议百科项目开发日志

**记录日期：** 2026-11-19  
**项目名称：** 卫戍协议百科（SENTINEL PROTOCOL WIKI）  
**项目状态：** 初步框架已搭建，可以正常运行

## 1. 项目目标

制作一个以《明日方舟》卫戍协议为主题的资料百科网站。

计划包含以下内容：

- 参战干员资料
- 干员技能与属性数值
- 装备和道具资料
- 卫戍协议机制与攻略
- 搜索和筛选功能
- 数据计算器

主要资料来源：  
[PRTS Wiki - 卫戍协议·规程](https://prts.wiki/w/卫戍协议·规程)

## 2. 开发环境

- 操作系统：Windows
- IDE：IntelliJ IDEA
- 框架：Astro
- 语言：TypeScript、HTML、CSS
- 运行环境：Node.js
- 版本管理：Git
- 远程代码仓库：计划使用 GitHub

## 6. 开发约定

- 尽量将数据与页面结构分离。
- 干员、装备等资料优先保存在独立数据文件中。
- 重要数据尽量对照 PRTS Wiki 核实，不确定的数据不要当作事实。
- 每次修改后测试页面，确认没有影响已有功能。
- 使用 Git 记录每次重要修改。
